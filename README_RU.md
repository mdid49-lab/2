# iTAG Controller

Android-приложение для BLE-брелка iTAG с адресом:

`5B:98:5C:0C:8B:0A`

Минимальная версия Android: **5.0 / API 21**.

## Что реализовано

- автоматическая проверка Bluetooth;
- системный запрос на включение Bluetooth;
- автоматический BLE-поиск при запуске;
- подключение только к указанному MAC-адресу;
- красная/зелёная индикация связи;
- кнопка «вкл. стартер»;
- таймер стартера в секундах;
- отправка стандартного Bluetooth Alert Level через `0x2A06`;
- таймер напряжения в минутах;
- сохранение параметров;
- определение возможности записи в пользовательскую характеристику `FFE1`.

## Важное ограничение по LED

По предоставленному скриншоту GATT:

- сервис `FFE0`;
- характеристика `FFE1`;
- у `FFE1` указано `NOTIFY, READ`.

WRITE-свойство на `FFE1` на скриншоте отсутствует. Поэтому приложение **не отправляет неизвестную команду** для LED. Это сделано специально, чтобы не послать на плату случайный байт.

Для полноценного управления LED нужно получить реальную команду устройства. Её можно определить по дампу BLE-трафика при нажатии штатной кнопки iTAG или экспериментально через BLE-анализатор.

## Сборка APK

Открыть папку проекта в Android Studio и выполнить:

`Build -> Build App Bundle(s) / APK(s) -> Build APK(s)`

APK будет находиться примерно здесь:

`app/build/outputs/apk/debug/app-debug.apk`

Для Android 12+ приложение попросит разрешения Bluetooth.
Для Android 6–11 для BLE-сканирования потребуется разрешение геолокации, поскольку это требование Android.
