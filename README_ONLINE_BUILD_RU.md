# iTAG Controller — онлайн-сборка APK

Проект рассчитан на сборку через **GitHub Actions**, без Android Studio.

## Как получить APK

1. Создайте новый репозиторий на GitHub.
2. Загрузите в него **все файлы и папки из этого проекта**.
3. Откройте вкладку **Actions**.
4. Выберите workflow **Build iTAG Controller APK**.
5. Нажмите **Run workflow**.
6. После завершения откройте результат запуска.
7. В разделе **Artifacts** скачайте `iTAG-Controller-debug`.
8. В архиве будет `app-debug.apk`.

## Важно

Проект специально использует `minSdk 21` (Android 5.0).

На Android 12+ приложение запросит Bluetooth Scan/Connect.
На Android 6–11 BLE-сканирование требует разрешение геолокации.

Приложение автоматически ищет только:

`5B:98:5C:0C:8B:0A`

Управление стартером использует подтверждённую характеристику:

`1802 / 2A06`

`02` = включить, `00` = выключить.

Управление LED пока не отправляет неподтверждённые команды, поскольку предоставленный GATT показывает `FFE1` как READ/NOTIFY без WRITE.
